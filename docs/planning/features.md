# CardFlipper Features

Last updated: 2026-08-09

## Version 1

### Vocabulary library

- Create, edit, search, tag, filter, and delete cards.
- Store multiple Russian meanings and multiple English variants.
- Store optional IPA and multiple parts of speech per English variant.
- Warn about normalized duplicates while allowing the save.

### Dictionary assistance

- Suggest the first available IPA and part of speech for English input.
- Keep suggestions editable and optional.
- Support cancellation, timeout, not-found, and offline states.

### Pronunciation

- Speak English values with the system British English voice.

### Study setup

- Select Russian-to-English or English-to-Russian.
- Select any number of tags with OR semantics.
- Use every matching card, or the full library when no tag is selected.

### Study session

- Shuffle once at start.
- Tap to flip.
- Remove remembered cards from the queue.
- Append forgotten cards to the queue.
- Confirm before abandoning a session.

### Result

- Show unique card count and total forgotten taps.
- Return to the library or repeat the same selection.

### Study progress

- Count time automatically only while card review is active in the foreground.
- Accumulate multiple sessions into a local daily total with a configurable goal.
- Mark completed days in the statistics calendar without recalculating history.
- Show a fixed paused snapshot in a Live Activity while the app is inactive.

## Later Candidates

- Spaced repetition.
- Streak counters and achievements.
- Import/export and backup.
- Cloud synchronization.
- Automatic translation.
- Written and spoken answer modes.
- iPad support.

These candidates are not architectural requirements for version 1.
