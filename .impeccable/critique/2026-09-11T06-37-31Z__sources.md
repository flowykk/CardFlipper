# CardFlipper — полный UX/UI-аудит

Method: dual-agent (A: /root/ux_design_review · B: /root/ux_detector)

Дата: 2026-09-11. Scope: актуальный SwiftUI-код, 3 filmstrip и 15 walkthrough screenshots, settings screenshots, свежий build и simulator captures на iPhone 17 Pro/iOS 26.2, отдельный dark-mode/max-Dynamic-Type pass на iPhone 16e/iOS 18.6. Browser overlay неприменим к native SwiftUI. Deterministic detector вернул `[]`; это coverage gap, не доказательство отсутствия UX-проблем.

## Итог

Функциональный фундамент хороший, но до polished release я бы не выпускал без исправления целостности данных, защиты длинной формы и adaptive layout. Самый сильный экран — Study Session. Самые слабые места — доверие к local-first данным, root navigation, перегруженный editor и максимальный Dynamic Type.

Design specificity: medium-low. Карточка и flip узнаваемы, но Library/Setup/Result выглядят как универсальный SwiftUI CRUD. Десять app icons несут больше характера, чем ежедневный learning loop.

## Что уже хорошо

- Study loop имеет одну ясную задачу, крупную карточку, progress и адаптивную пару assessment-кнопок.
- Loading/error/empty/retry/delete confirmation/duplicate/lookup states в основном предусмотрены.
- База accessibility выше средней: 44pt targets, selected traits, VoiceOver focus transfer, internal scroll для длинной карточки, Reduce Motion fallback.
- Empty/filter states различаются; есть clear filters, поиск, bulk tagging и repeat забытых карточек.
- В обычном размере ключевые экраны чистые, не страдают от случайного clipping.

## 5 приоритетных проблем

### P1 — local-first обещание нарушается двумя скрытыми потерями данных

- При ошибке чтения Export создаёт внешне валидный документ с `cards: []`, а completion игнорируется. Пользователь получает ложное чувство успешного backup.
- Bulk add tags пересобирает `VocabularyCard` без `isLearned`, поэтому выученные карточки молча становятся невыученными.

Исправить: export должен блокироваться на fetch error и завершаться явным success/failure с количеством карточек и именем файла; bulk update должен сохранять все поля модели, лучше через `copy/updating(tags:)`, а не ручную реконструкцию.

Evidence: `RootView.swift:178,405`; `LibraryViewModel.swift:204-215`; `VocabularyCard.swift:12-20`.

### P1 — editor теряет черновик и допускает повторное сохранение

Cancel и swipe-down закрывают длинную форму без dirty-state confirmation. Save остаётся активным во время операции; новый UUID создаётся на каждый snapshot, поэтому быстрый double tap способен создать дубликаты.

Исправить: dirty tracking, `interactiveDismissDisabled(isDirty)`, confirmation с «Продолжить редактирование / Отменить изменения», `isSaving`, idempotent save с UUID, создаваемым один раз при старте draft.

Evidence: `RootView.swift:358`; `CardEditorView.swift:86,129`; `CardEditorViewModel.swift:408,445-456`.

### P1 — максимальный Dynamic Type ломает основной сценарий

На iPhone 16e/MAX AX: app-icon labels обрезаются до `Oce/an`, `Cor/al`; timer pill становится огромным, перекрывает карточку и нижние действия; после requeue UI automation/AX tree не находит `Remember`; setup превращается в длинный экран, где нижние элементы оказываются далеко за fold. Empty-screen Add визуально есть, но `library.add` не находится automation tree.

Исправить: при accessibility sizes переключать segmented controls в vertical Picker/list, timer — в две короткие подписанные строки без giant capsule, assessment — закреплять в safe-area inset, icon chooser — adaptive grid/list с многострочными labels. Проверить AX tree и hit targets, а не только screenshots.

### P1 — root navigation не выражает главный пользовательский путь

Пять одинаково весомых icon-only кнопок сверху заставляют угадывать: gear, chart, stack, checklist, plus. `rectangle.stack.fill` для Study семантически похож на Library. Learned/Delete спрятаны только в swipe. В empty state поиск занимает место, хотя искать нечего.

Исправить: сделать `Study` заметным текстовым primary action с progress/goal, оставить Add рядом; Settings/Statistics/Bulk перенести в secondary menu или явные tabs. Для study лучше `graduationcap.fill` или `play.rectangle.fill`; Learned показывать в строке badge/check и дать доступное context menu. Search скрывать до появления карточек.

### P2 — editor предъявляет ошибки и экспертные поля раньше времени

Новая карточка открывается сразу с красными validation errors. В одном блоке одновременно value, speech, IPA, 14 POS, examples, lookup, add/remove. English placeholder реально ellipsized (`Enter an English tr…`) из-за двух соседних 44pt actions. Автоматический lookup сосуществует с кнопкой Lookup и может перезаписать вручную введённый IPA.

Исправить: показывать validation после blur/save attempt; первым слоем оставить Russian + English + Save, вторым раскрывать IPA/POS/examples/tags. POS — searchable menu с recent options. Speaker/remove переносить по `ViewThatFits`; автоматический lookup не должен менять dirty/manual IPA без подтверждения.

## По экранам

### Library / empty / list

- Empty state слишком холодный и пустой. Добавить secondary `Import cards` и, возможно, `Try sample cards`; импорт сейчас спрятан в Settings.
- `Show translations` неточно: фактически показываются русские значения. Лучше `Show Russian meanings` или явный bilingual row.
- В All-list не виден Learned-state. Нужен постоянный marker; gesture оставить accelerator.
- Tags создаются только через editor, а управляются через generic ellipsis. Нужен явный экран/tag menu с rename, merge, delete и количеством карточек.
- `ellipsis.circle` для управления тегом слишком общий. `tag`/`tag.fill` + label семантически лучше.
- `books.vertical` на result и `rectangle.stack` в library — выбрать один символ.
- Переход `.move(edge: .top) + opacity` при фильтрации может выглядеть как удаление. Оставить stable list + opacity/content transition.

### Card editor

- Быстрый путь должен укладываться в 2 поля и одну кнопку; IPA/POS/examples/tags — progressive disclosure.
- Горизонтальный POS strip допустим как intentional peek, но 14 choices создают decision fatigue. Нужны recent/common POS и `More`.
- Длинные tag chips принудительно `.lineLimit(1)` и будут резаться. Нужна adaptive wrapping и полный accessibility label.
- Usage examples хорошо структурированы, но disabled state до POS не объясняет причинно-следственную связь достаточно рано.
- После save нужен явный краткий outcome (`Card added`) и понятный возврат к созданной строке.

### Study setup/session/result

- Setup хорошо сгруппирован, но direction/status segmented controls не выдерживают accessibility sizes. Нужен adaptive vertical layout.
- Core flip в историческом filmstrip показывает ghost/double text в середине. Контент следует менять строго около 90°, фиксируя высоту; при Reduce Motion оставить crossfade.
- Answer-side имеет тот же VoiceOver hint `reveal answer`, хотя tap уже скрывает ответ. Нужен `Hide answer` или отключение обратного flip после reveal.
- `Don't remember` оранжевый и `Remember` синий понятны по словам/иконкам, но пользовательский accent способен разрушить контраст и смысл цветов.
- Timer `00:12 / +00:12` криптичен. Формат: `Today 12s · Session 12s`; локализовать VoiceOver label, сейчас он hardcoded English.
- Result показывает completion, но не learning insight. Добавить difficult cards, recall rate, duration и next-step; `1 extra attempt` заменить на `1 card repeated`.
- Активная session не переживает kill/relaunch. Для distracted mobile use сохранить queue/current index/answers/timer checkpoint.

### Statistics

- Totals без trend/сравнения плохо помогают принимать решения. Добавить `vs previous 7 days`, streak, recall/repeat rate.
- Calendar не имеет legend; future, no-study и missed-goal состояния недостаточно различимы.
- Month chevrons/day cells требуют фактического 44×44 hit frame и AX-аудита.
- Zero state должен объяснить, что появится после первой session, а не просто показывать нули.

### Settings / appearance / app icons / import-export

- Arbitrary ColorPicker меняет global tint без contrast guardrail. Лучше curated WCAG-safe palette + System default; либо вычислять foreground и предупреждать о contrast в light/dark/Increase Contrast.
- App icon carousel на обычном размере показывает intentional next-item peek — это не clipping bug. Но нет page/count affordance, а на MAX AX подписи реально ломаются. Предпочтительнее chooser sheet с adaptive grid и полным именем.
- Десять icon styles выглядят как разные продукты. Сохранить общую форму, типографику и flip motif, варьировать цвет/texture.
- Simulator вернул `Couldn’t Change Icon`; это надо подтвердить на physical device, прежде чем считать product bug.
- Import success должен показывать Added/Merged/Skipped/Conflicts. Сейчас catalog теряет уже рассчитанные counts.

## Иконки

- Подходят: gear, chart, plus, checkmark.circle, uturn/requeue, timer.
- Сомнительны: stack для Study; books vs stack для одной Library; ellipsis для tag management.
- Иконка без label приемлема только для общеизвестных Add/Settings/Close. Study, Bulk, Statistics и tag management должны иметь текст хотя бы в меню/toolbar role.
- Не полагаться только на цвет: выбранность и learned-state должны иметь shape/icon/text.

## Что убрать, изменить, добавить, отрефакторить

Убрать: красные ошибки при первом открытии, бесполезный search в пустой библиотеке, равноправие пяти toolbar glyphs, fallback empty export, произвольный accent без проверки, повторный flip с неверным hint.

Изменить: home вокруг `Study today`, editor на basic/advanced layers, timer copy, result metrics, Learned visibility, icon semantics, adaptive layouts, import/export feedback.

Добавить: draft protection, idempotent save, undo/snackbar для Learned/Delete/Bulk, explicit import on empty state, visible study goal/progress, stats legend/trends, session restoration, accessible palette, AX/MAX-Dynamic-Type regression suite.

Рефакторить: модельные updates через value-preserving copy methods; export как fallible state machine; reusable adaptive controls; единый semantic icon catalog; lookup ownership/manual override policy; single source of truth для library/status/assessment semantics.
