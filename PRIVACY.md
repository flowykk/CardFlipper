# Политика конфиденциальности CardFlipper

Дата вступления в силу: 18 сентября 2026 года.

CardFlipper — приложение для создания и изучения карточек. Для использования приложения не требуется регистрация или создание учётной записи.

## Данные на устройстве

Карточки, переводы, примеры, теги, настройки, история занятий и статистика сохраняются локально на устройстве пользователя. Разработчик CardFlipper не получает доступ к этим данным.

CardFlipper не использует рекламу, системы аналитики или технологии отслеживания пользователей.

## Словарные подсказки

При вводе английского слова CardFlipper может отправить это слово сервису [Free Dictionary API](https://dictionaryapi.dev/) через защищённое HTTPS-соединение. Это необходимо для получения транскрипции и части речи.

Вместе с запросом стороннему сервису могут быть доступны IP-адрес и стандартная техническая информация сетевого соединения. Обработка этих данных осуществляется сторонним сервисом. Разработчик CardFlipper не получает и не хранит историю таких запросов.

Словарные подсказки являются необязательными. Карточки можно создавать и редактировать вручную без использования этой функции.

## Импорт и экспорт

Импорт и экспорт карточек выполняются только по явному действию пользователя. Пользователь самостоятельно выбирает файл и место его сохранения.

## Удаление данных

Пользователь может удалить отдельные карточки внутри приложения. Все локальные данные CardFlipper также удаляются при удалении приложения с устройства.

## Контакты

По вопросам конфиденциальности создайте обращение в [репозитории CardFlipper](https://github.com/flowykk/CardFlipper/issues).
